# Lazer YouTube Music Plugin — 双轨封面视觉融合与主页合辑常驻规划

> 编写日期：2026-11-13  
> 对应版本：v0.1.8  
> 状态：**规划定稿，待实施**

---

## 📌 背景与设计目标

### 1. 现象分析
- **Lazer 客户端的封面墙动画**：主页底部的“为你创建的电台”拥有极其灵动的两排封面跑马灯马赛克动画（`_MovingCoverMosaic`），以 30 FPS 缓缓平移，这是由 Lazer 本地 Flutter 渲染引擎利用插件下发的高清单曲封面拼装而成的原生视觉特效。
- **YouTube 官方下发的 Mixart 艺术定制大卡片**：YouTube 针对个人专属歌单（如归档合辑 Archive Mix、重放合辑 Replay Mix、发现合辑 Discover Mix、新歌合辑 New Release Mix 等）会下发动态算法生成的专属抽象几何拼贴图（`https://music.youtube.com/image/mixart?r=...`）。
- **痛点**：当用户刚打开应用时，YouTube 首屏推合辑，主页呈现“编辑精选”大卡片；但只要用户连续点播了几首具体单曲，YouTube 推荐算法会把首屏切成单曲流推荐，导致“编辑精选”大卡片暂时隐身，视觉体验不稳定。

### 2. 核心设计目标
实现 **“双轨视觉供给（Dual-Track Visual Supply）”**：
- **上轨（YouTube 官方算法艺术合辑轨）**：向 `feed.editorialPlaylists` 稳定供应用户专属 Mix，主页中段 100% 稳定呈现官方下发的 `mixart` 几何艺术封面大卡片，永不被单曲流冲掉。
- **下轨（Lazer 客户端原生动画素材轨）**：向 `feed.quick` 与 `feed.daily` 供应真实的高清单曲列表，让主页底部的“为你创建的电台”与顶部的快捷电台流畅播放 30 FPS 跑马灯马赛克封面墙动画。
