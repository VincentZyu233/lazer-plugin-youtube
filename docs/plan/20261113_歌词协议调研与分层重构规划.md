### 🔴 任务 B：歌手搜索缺少头像 & 任务 C：专辑搜索不准

#### 1. 根因分析
- 早期 `ytm/catalog.lua` 在发起搜索时，请求体中硬编码了纯歌曲过滤芯片。
- 导致 YouTube 返回的全部是单曲，没有真正的歌手和专辑对象。
- 早期代码中歌手与专辑是从歌曲所属的副标题标签里临时提取的，因此歌手没有独立头像，搜出来的专辑也全是单曲对应的所属专辑。

#### 2. 实测调研突破（综合全量搜索）
通过调用 `/youtubei/v1/search`：
1. **顶层顶级歌手卡片（Top Card）**：
   - 命中 `musicCardShelfRenderer`：
     - 名字：`card.title.runs[0].text`
     - 副标题：`"音乐人 • 每月听众：..."`
     - **真实高清圆形头像**：`card.thumbnail.musicThumbnailRenderer.thumbnail.thumbnails`
     - 歌手 ID：`card.title.runs[0].navigationEndpoint.browseEndpoint.browseId`
2. **混合分类条目（Item Sections）**：
   - `MUSIC_PAGE_TYPE_ARTIST`：独立音乐人列表，每个都自带独立的高清头像 Thumbnail。
   - `MUSIC_PAGE_TYPE_ALBUM`：真正的独立专辑/单曲 EP 列表，自带专辑封面、年份和作者。
   - `MUSIC_PAGE_TYPE_PLAYLIST`：精选歌单列表。
   - `SONG/VIDEO`：单曲与歌曲视频。

#### 3. 落地实施方案
- 改造 `search` 解析器：
  1. 优先提取 `musicCardShelfRenderer`（顶级命中项，直接作为第 1 位歌手，填入高清头像）；
  2. 遍历 `itemSectionRenderer` 中的 `musicResponsiveListItemRenderer`，根据 `pageType` 精准归类进 `artists`、`albums`、`playlists`、`songs`；
  3. 各个实体直接取用其自身的 `thumbnail`，彻底告别空头像与伪专辑。

### 🟢 任务 E：YouTube Music 歌词接入（Lyrics）

#### 1. Lazer 宿主契约要求（`lib/gateway/lua_music_gateway.dart:476`）
- 宿主通过 `lyrics` 操作调用插件：`{ id = songId }`
- 返回数组，每个元素包含：
  ```lua
  return {
    {
      lines = {
        { text = "第一句歌词", startMs = 0 },
        { text = "第二句歌词", startMs = 3500 }
      },
      synced = false, -- 若有时序则为 true，纯文本为 false
      lrc = "[00:00.00]第一句歌词\n[00:03.50]第二句歌词..."
    }
  }
  ```

#### 2. 实测调用链路
1. **第 1 步：查歌词入口**  
   - POST `https://music.youtube.com/youtubei/v1/next`  
   - 携带 `{ videoId: songId }`  
   - 在 `tabbedRenderer.watchNextTabbedResultsRenderer.tabs` 中遍历找到标题为 `"歌词"`（或 `browseEndpoint.browseId` 以 `MPLY` 开头）的 Tab，提取到 `browseId`。
2. **第 2 步：拉取歌词正文**  
   - POST `https://music.youtube.com/youtubei/v1/browse`  
   - 携带 `{ browseId: "MPLY..." }`  
   - 响应中提取：`contents.sectionListRenderer.contents[0].musicDescriptionShelfRenderer`：
     - `description.runs`：纯文本逐行歌词正文（官方 LyricFind 歌词全本）
     - `footer.runs`：版权来源信息
3. **第 3 步：组装返回**  
   - 将文本按换行切分后组装成 `lines`，返回给 Lazer，Lazer 的播放器全屏、歌词页、桌面歌词即可展示。

### 🟢 任务 D：YouTube 推荐歌单 / Radio 漫游接入

#### 1. Lazer 宿主契约要求（`lib/gateway/lua_music_gateway.dart:594`）
- 宿主调用 `radio` 操作：
  `{ kind = "personal" | "heart" | "artist", seed = songId, playlist = playlistId, limit = 30 }`
- 插件返回 `List<MusicSong>` 队列。

#### 2. 调用流程
1. 若指定了 `seed`（单曲 ID）：构造 `RDAMVM` + `seed` 作为电台歌单种子；
2. 若未指定种子：默认从首页第 1 首推荐单曲提取种子；
3. 请求 `/youtubei/v1/next` 自动下发连续播放的 25~50 首关联单曲流。
