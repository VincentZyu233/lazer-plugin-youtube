# 🎵 Lazer YouTube Music 插件 v0.1.14 发布说明

## 🌟 核心更新亮点

### 1. 歌手解析绝对净化与播放量文本彻底剥离
- **修复播放量挤占歌手名字缺陷**：彻底解决了特定视频 / MV 条目及热门卡片中，播放次数文本（如 `播放次数：1743万`、`335万`）被误判为歌手名字的严重 Bug。
- **真实艺人归位**：严格提取 `MUSIC_PAGE_TYPE_ARTIST` 与 `MUSIC_PAGE_TYPE_USER_CHANNEL` 实体，副标题 100% 呈现干净的歌手名称（如 `いよわ`、`初音ミク`）。

### 2. 第二列（专辑列）创新重构：`[播放量] 专辑名`
- **播放量国际化换算**：采用 YouTube 标准国际化格式展示播放热度（如 `[17M 播放]`、`[3.4M 播放]`、`[850K 播放]`），支持英文 `K/M/B` 与中文 `万/亿` 智能双向转换。
- **无播放量优雅兜底**：录音室官方音轨等未下发播放量的条目统一展示 `[未知播放]`，全列表对齐整齐划一。
- **彻底告别 `YouTube Music` 假专辑占位**：无实体大碟的单曲 / MV 优先以歌曲同名承载（如 `[17M 播放] ももいろの鍵`），彻底移除无意义的 `YouTube Music` 字符串。

### 3. 文档与工程规范提升
- 在 `test/` 与 `tools/` 根目录补全标准 Tree 格式目录清单与脚本注释说明。
