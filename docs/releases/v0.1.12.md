# Lazer YouTube Gateway v0.1.12

### 亮点更新
1. **主页官方动态 Mixart 深度下发与持久化常驻**
   - 增加对 `FEmusic_home` 延续响应（Continuation）的深度解析，完整提取并呈现 YouTube 下发的专属合辑（如“新しい曲や過去のお気に入り” / “Mixed for you”）以及真实的 `https://music.youtube.com/image/mixart?r=...` 动态封面。
   - 官方兜底合辑封面全面切换为 jsdelivr 高速全球 CDN，彻底告别 404 与灰色音符图标。
   - 专属合辑与封面快照持久化至 Lazer 隔离存储，离线或首屏零延迟瞬时秒开。

2. **搜索歌手归属与日文/中文/英文全语言对齐**
   - 修复歌手卡片热门歌曲（如いよわ的《ももいろの鍵》）因副标题缺失直接回退为 "YouTube Music" 的缺陷，深度绑定卡片歌手实体。
   - 过滤日文 `曲`、`動画` 与各类分割标点，杜绝副标题类型标签被误识别为歌手名。
   - 多语言类型标签全面适配（`アーティスト`、`アルバム`、`プレイリスト` 等）。

3. **歌手频道与 Topic 频道曲目全量捕获**
   - 修复单曲详情丢弃真实 `channelId` 的问题，并在歌手服务中增加虚拟 ID 向真实 YouTube Channel 的反查支持。
   - 针对 YouTube Topic / 独立频道无 `musicShelfRenderer` 的结构，自适应遍历全量 Carousel 货架提取单曲，杜绝“空的 Topic”和“暂无热门歌曲”。

4. **我喜欢的音乐与长列表防抖容灾**
   - 增加首屏网络抖动 1 次自动重试与磁盘快照双重防护，保障收藏夹与喜欢歌单极速呈现。
