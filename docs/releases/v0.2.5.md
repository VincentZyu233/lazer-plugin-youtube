# Lazer YouTube Plugin v0.2.5

### 🩹 Cookie 登录修复与插件市场上架

1. **修复 0.2.x 全版本 Cookie 登录必然失败的问题**：
   - 根因：宿主 `lua_dardo_plus` 的 `string.match` 直接调用 Dart `RegExp`，Lua 的 `%s`
     字符类会退化成字面量，`^%s*(.-)%s*$` 恒返回 `nil`。
   - 0.2.x 用它裁剪 Cookie，会把整条凭据清空，再被空串判定误导去读取当前 VM 不可见的
     本地 storage，最终统一报「连接失败，请检查网络」。
   - 现改为 `auth_cookie.trim` 纯字节裁剪（`string.byte` / `string.sub`）。
   - `get_sapisid` 同步移除 `%s` / `%-` 模式兜底，改为按字段名 + 边界字节扫描，保证
     原始 Cookie 签名不被破坏。

2. **修复歌单曲目数恒为 0**：
   - `browse.lua` 的 `string.match(sec_sub, "(%d+)")` 在宿主上恒返回 `nil`。
   - 改用已有的 `nav.extract_number` 纯字节扫描，并对结果取整。

3. **修复 `tools/get_cookie.js` 抓取成功后卡死**：
   - 移除「必须先通过 InnerTube 校验才判定成功」的阻塞依赖，核心 Cookie 齐备即刻捕获。
   - 账号昵称/头像改为从浏览器页面 DOM 直接读取（零网络开销）。
   - InnerTube `account_menu` 校验降级为可选的 2 秒超时增强，网络不通不再无限挂起。
   - 修正 `fetchAccountProfile` 中误用 Lua 语法写成的 JS 正则 `[;%s]`（`%s` 在 JS 中是
     「分号 / 百分号 / 字母 s」），该错误会在 SAPISID 含小写 `s` 时截断签名。

4. **文档与测试**：
   - 明确 `storage.json` 的生效时机：宿主仅在插件 VM 启动时读取一次，运行中注入需重启
     Lazer，或直接 `Ctrl+V` 粘贴登录。
   - 新增 `test/test_cookie_trim.lua`（含源码守卫，防止 `%s` 裁剪回归）。
   - 新增 `test/test_playlist_header.lua`（英文/千分位/中文/小数/缺省用例）。

5. **工程化**：
   - 新增 tag 触发的 GitHub Actions 自动打包与 Release 发布流程。
   - 补充 MIT 许可证文件，插件正式收录于 Lazer 官方插件市场。
