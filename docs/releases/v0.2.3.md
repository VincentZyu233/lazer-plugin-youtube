# Release v0.2.3: 修复喜欢歌单加载死锁与账号头像自动同步

## 变更摘要

- **修复喜欢歌单 (`VLLM`) 加载死锁与界面长时间转圈**：
  - 移除了首屏拉取时阻塞式的 10 页连续 HTTP 请求循环，转为与 Lazer 宿主 `playlistTrackPages` 契约完美契合的流式增量分页架构。
  - 首屏秒级返回前 100 首已解析歌曲，后续分页在滑到底部时通过 `continuation` 按需即时加载，彻底告别超时转圈。
- **修复 Lua 5.4+ 循环常量错误导致鉴权崩溃**：
  - 修复了 `ytm/auth/cookie.lua` 中 `for raw_part in ... do local part = ...` 迭代变量不可赋值的问题，彻底消除 `attempt to assign to const variable 'part'` 异常。
- **自动同步 Google 频道真实头像**：
  - 在 `account.session()` 中增加了对头像状态的智能探测，若当前为 `default-user` 占位符或空，则自动通过 `account_menu` 抓取并持久化频道真实高清头像。
