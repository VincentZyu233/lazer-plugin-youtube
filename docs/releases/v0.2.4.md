# Lazer YouTube Plugin v0.2.4

### 🚀 稳定性与认证体验升级 (对标 0.1.15 稳定规范)

1. **剪贴板注入全面回归纯原生 `clip.exe`**：
   - 彻底废弃不可靠的 PowerShell 管道，采用 Windows 纯原生标准流写入。
   - 彻底解决超长 Cookie 在剪贴板中被截断、缺失 `SID`/`SAPISID` 导致报“连接失败”的问题。

2. **`account.session()` 100% 离线秒返**：
   - 严格遵循 0.1.15 离线优先原则，启动期间不发任何网络阻塞请求。
   - 严防空字符串 `user_id` 陷阱，杜绝 Dart 核心注销有效用户的 bug。

3. **`account.login_cookie()` 优雅降级容错**：
   - 引入网络抖动容错保护，当代理握手有延迟时，只要 Cookie 包含核心凭据，平稳落盘并进入已登录态。

4. **存储注入与使用体验优化**：
   - 自动注入时确保 `user_id` 与 `user_name` 具备合法初值。
   - 优化指引，推荐直接粘贴或冷启动进入。
