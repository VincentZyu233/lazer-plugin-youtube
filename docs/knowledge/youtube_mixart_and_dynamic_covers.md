## 🎨 什么是 Mix Art（个性化专属合辑封面）？

在使用 Lazer 或移动端播放 YouTube Music 时，用户常在“编辑精选”或“为您打造”板块看到一类极具艺术质感的封面——例如顶部印有大号现代字体 **`Replay MIX`**、**`My Supermix`**、**`Discover MIX`**，背景是柔和色彩过渡的几何网格，中间水平并排展示着 3 张专辑/单曲封面（如下图所示）。

这类封面并非唱片公司上传的静态 JPEG，而是 **YouTube / Google 服务端专门为算法合辑实时渲染生成的动态合成图**。

---

## ⚙️ YouTube 云端动态渲染机制

### 1. 服务端核心微服务与 URL 格式
YouTube 内部拥有高并发的图像生成渲染集群，其核心端点与请求格式如下：
```text
https://music.youtube.com/image/mixart?r=CAEYA...&w=540&h=225
```
其中 `r` 参数为 Protocol Buffers 序列化后的视觉配置指令，定义了布局模式、色卡（Palette）与绑定的素材清单。

### 2. 算法合成流水线（Pipeline）
1. **种子曲目提取**：根据用户针对该合辑（如 Replay Mix 重放合辑、Discover Mix 发现合辑）的近期真实收听历史与权重大数据，筛选出最具代表性的 3 首核心音轨。
2. **主题色提取（Color Extraction）**：服务端图像处理器分析这 3 张歌曲封面的主色调（Dominant Colors），计算出和谐的色彩梯级。
3. **背景几何网格渲染**：基于主题色生成带有纵向线条和柔和磨砂色块的背景画布。
4. **素材平铺与大字压印**：居中并排渲染 3 张 1:1 单曲封面，并在顶部居中压印半透明设计的英文字符（`Replay MIX`、`Supermix` 等）。
5. **边缘缓存与自适应更新**：生成的图像经由 Google CDN 边缘分发；当用户收听口味发生演进，服务端重新生成并使旧缓存失效。

## 📱 跨客户端呈现差异：为什么在网页版 (music.youtube.com) 找不到？

很多用户好奇：“为什么我在网页端怎么找都找不到这种好看的宽幅排版封面？”

| 客户端形态 | 展示形式 | 技术与交互原因 |
| :--- | :--- | :--- |
| **手机移动端**<br>*(Android / iOS App)* | 首页顶部 **横向滑动大卡片 (Carousel)** | 移动端屏幕狭长，16:9 或宽比例大卡片能带来最强烈的沉浸感与视觉焦点。 |
| **智能电视端**<br>*(Android TV / Apple TV / Cobalt)* | **10-Foot UI 巨幅海报轮播** | 电视大屏需要远距离观赏（客厅场景），这种带大字的海报级排版具有出色的可视性。 |
| **桌面网页端**<br>*(music.youtube.com)* | **强制 1:1 正方形卡片网格 (Square Grid)** | **网页端的死板网格约束**：Web 端为了多列瀑布流排列对齐，强制容器宽高比为 `1:1`。宽幅 Mix Art 会被裁切变形，因此 Web 端通常降级为 **2×2 四宫格单曲封面拼贴**，或者降级为正方形抽象波形纯色图标。 |
| **Lazer 客户端**<br>*(本插件实现)* | 首页中段 **「编辑精选」大卡片墙** | **完美释放宽版魅力**：Lazer 的首页卡片组件天生支持宽比例封面渲染。插件通过逆向 InnerTube 协议提取出这些高分辨率动态 Mix Art 并持久化常驻，在 PC 桌面上完整重现了 Google 最精美的大师级排版！ |

## 🛠️ 插件工程落地考量

在 `lazer-plugin-youtube` 中，我们采取了如下工程策略：
1. **协议下发嗅探**：深度遍历 `FEmusic_home` 及其 Continuation 响应中的 `musicTwoRowItemRenderer`，优先识别 `VLRDTM...` 与 `mixart?r=` 特征链接。
2. **持久化快照与优雅保底**：由于 YouTube 算法有时会临时把首屏合辑切换为普通单曲流，插件在 `discover.lua` 中构建了双轨持久化缓存，并在极端冷启动时配备本地高精 Mixart 种子兜底，确保主页中段的视觉盛宴永不落空。
